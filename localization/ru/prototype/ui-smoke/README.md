# Дымовой тест интерфейса: «изменилась ли страница?»

Набор Deno и перебор проверяют только движок (`fins.js`, `prop.js`, …),
оставляя `web/app.js` и `web/ui/` без покрытия. Этот тест управляет реальной
страницей в Chrome без интерфейса по фиксированному сценарию из 85 шагов,
записывает всё видимое после каждого шага и сравнивает с базовой сборкой.

```sh
prototype/ui-smoke/vs-base.sh                  # vs origin/main, models cone + lbracket (~1.5 min)
prototype/ui-smoke/vs-base.sh <sha>            # vs any commit that has window.__sf.camera
MODELS="cone tshape" prototype/ui-smoke/vs-base.sh
KEEP=/some/dir prototype/ui-smoke/vs-base.sh   # keep the JSON dumps

# one run, to look at or to diff by hand
deno run -A prototype/ui-smoke/ui-smoke.js --model cone --out run.json
deno run -A prototype/ui-smoke/compare.js base.json run.json
```

**Сценарий:** загрузка → повороты X, Y → включение рёбер → удаление ближайшего ребра
(наведение, нажатие, Esc, восстановление, ⌘Z, повтор) → PETG → площадка: Надёжная
фиксация / Свои настройки / зазор / Автоматически → перемычки выкл./вкл. → распорки →
ромбовидные отверстия → плотность 80 → Ручное размещение: стенка поперёк нависания,
затем Esc, отмена, очистка и отмена этих действий → Автоматически с ручной стенкой →
«+ Добавить» вкл./выкл. → стрелка нагрузки вверх / вправо / подбор / очистка →
просмотр слоёв → положить на грань + отмена → подбор ориентации, выбор №2,
сворачивание → сброс → рёбра выкл./вкл. → нависание 55° → свои габариты →
6× отмена → включение удаления и импорт второй модели → STEP с двумя телами:
окно выбора, выбор обоих, объединение → 3MF с двумя объектами: окно выбора,
отмена, импорт копии, загрузка.

**После каждого шага записываются:** все элементы с `id` (текст, скрытие, блокировка,
класс, значение, варианты списка, подсказка (i)); кватернион детали; число
треугольников и контрольная сумма рёбер, площадки и ручных стенок; геометрия экспорта;
все видимые сетки и линии (тип, цвет, число вершин), непрозрачность материалов;
курсор холста; все ошибки и предупреждения консоли. `s-time` и `fps` пропускаются,
поскольку меняются между запусками. Два запуска одной сборки идентичны, поэтому
каждая строка вывода `compare.js` означает реальное изменение.

**Назначение:** рефакторинг с сохранением поведения (задача #22). При намеренном
изменении интерфейса тест перечисляет все места, где оно проявилось, и помогает
проверить, что остальное не изменилось.

**Требования:** Deno и локальный Chrome (`CHROME=/path/to/chrome` переопределяет
стандартный путь macOS). Тест сам раздаёт `web/` и `prototype/stress/models/`,
поэтому сервер разработки и игнорируемые git файлы `dev-models` не нужны.
Chrome запускается по одному: два параллельных экземпляра приводили к зависанию GPU-процесса.

**Не проверяются:** перетаскивание колец манипулятора, импорт перетаскиванием
(используется поле выбора файла) и скачивание экспорта (проверяется геометрия,
а не байты файла). При изменениях этих функций проверяйте их вручную.
