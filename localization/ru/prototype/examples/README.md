# Примеры моделей для логики поддержек

Формы выбраны потому, что сейчас движок обрабатывает их с трудом. Также здесь есть
проверочный скрипт, который оценивает, какая ДОЛЯ ПЛОЩАДИ нависаний фактически получает
опору. Набор стресс-тестов (`prototype/stress/`) считает случай успешным, как только
построена хотя бы одна стенка. Поэтому изогнутый потолок с одной стенкой под ним проходит
там проверку, а здесь получает оценку 15%.

    python3 prototype/examples/gen.py            # заново создать models/ (trimesh + manifold3d)
    deno run -A prototype/examples/probe.js      # все модели вертикально и с наклоном 30°
    deno run -A prototype/examples/probe.js bowl mushroom

    pip install thingi10k
    python3 prototype/examples/fetch_thingi.py   # real/: 19 файлов Thingiverse (~10 ГБ при первой загрузке)
    deno run -A prototype/examples/probe.js --real

Каталог `real/` игнорируется Git: каждый файл сохраняет собственную лицензию Thingiverse
(она указана в `real/CREDITS.md`), поэтому модели загружаются для локального тестирования,
но не добавляются в репозиторий. Их выбрали вручную по контактному листу: это целые,
вертикально ориентированные объекты, а не части наборов. Миниатюры также сохраняются
масштабированными до высоты 32 мм.

Группы:

- **высокие / с высоким потолком** (`mushroom`, `table`, `shelf`, `bridge_span`):
  поддерживаются нормально, но каждая стенка начинается от стола. `stilt mm` — суммарная
  высота стенок от стола до детали, которую могли бы сократить разветвлённые поддержки
  (задача #8);
- **изогнутые** (`bowl`, `dome_ceiling`, `hook`, `vase_flare`, `torus_flat`):
  нижние поверхности, изогнутые в плане и/или сечении;
- **миниатюры** (`mini_figure`, `mini_cape`, `mini_dragon_wing`): фигуры размером
  около 30 мм с небольшими тонкими нависаниями вблизи минимальных размеров движка.

## Что измеряет проверочный скрипт

Используется автоматический режим так же, как в приложении:
`analyze(topo, 45, rot)`, затем
`buildFins(topo, res, rot, {mode:'auto', bedPad:true, tines:true})`.

- `held%`: площадь нависаний, центроид грани которых в плане находится не дальше
  `maxUnsupportedSpan/2` от вершины стенки и на 0–1,5 мм выше неё либо лежит на столе.
  Это приближённая оценка: перед тем как доверять числу, проверьте случай визуализацией
  или нарезкой;
- `walls` / `onPart`: число построенных стенок и число стенок, стоящих на детали,
  а не на столе;
- `stilt mm`, `g`: суммарная высота стоящих на столе стенок, а также масса поддержек
  и площадки для PLA;
- `skipped`: причины пропуска из `buildProps` (`sliver` означает участок площадью
  менее 12 мм², который был отброшен).

Ручной режим не измеряется.
